How good is the model?

F1 on Shopee test products the model never saw (0 = useless, 1 = perfect). Bars show 95% confidence intervals.

How it works: CLIP reads the photo, a multilingual language model reads the title, both are compressed to 32 numbers each (PCA whitening), and a logistic-regression model trained on 34,250 Shopee listings scores each look-alike using photo, title, size/pack-number and neighbour clues. Price is never used to decide a match.
"Same product" = same model (probability ≥ 0.90) with matching colour, size and pack; "other colour/pack" = same model but a different colour, size, pack or combo. Prices are 2023 Kaggle snapshots of Amazon India, not live. Photos load from Amazon's image servers. Indian match quality was checked on 60 fresh held-out pairs labelled by Claude (an AI assistant), not by human annotators.
